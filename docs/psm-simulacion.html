Cortes Transversales

Capitulo 16 Simulación Monte Carlo: OLS vs. PSM

¿Por qué no basta con OLS?

El supuesto central de los métodos de matching es la Conditional Independence Assumption (CIA): una vez condicionamos en las covariables observadas \(X\), el tratamiento es como si fuera aleatorio. Si la CIA se cumple, OLS también debería estimar el efecto causal (simplemente controlando por \(X\)). ¿Entonces para qué sirve el PSM?

La respuesta es que OLS y PSM no son equivalentes cuando el modelo lineal está mal especificado o cuando hay desequilibrio en la distribución de las covariables entre tratados y controles. PSM construye explícitamente un grupo de comparación balanceado, mientras que OLS extrapola linealmente incluso fuera de la región de soporte común.

Para ver esto en acción usamos una simulación Monte Carlo con verdad conocida.

El diseño del experimento

Proceso generador de datos (DGP)

clear all
set seed 2025
set obs 1000

gen x1 = rnormal()        // covariable que genera selección
gen x2 = rnormal()        // covariable irrelevante
gen u  = rnormal()        // error del resultado

* Tratamiento: probabilidad depende solo de x1
gen p = invlogit(0.5*x1)
gen D = rbinomial(1, p)

* Resultado: efecto VERDADERO del tratamiento = 2
gen y = 2*D + 0.5*x1 + u

Tres puntos clave del DGP:

  1. x1 afecta tanto la probabilidad de tratamiento como el resultado → selección en observables
  2. x2 es irrelevante: no afecta \(D\) ni \(y\) → covariable “ruido”
  3. El efecto causal verdadero es \(\tau = 2\) por diseño

El tratado promedio tiene x1 más alto (mayor probabilidad de selección), y también tiene y más alto por esa razón, independientemente del tratamiento. OLS sin controles confunde esto con el efecto causal.

Sesgo esperado en OLS sin controles

La diferencia de medias (= OLS sin controles) estima:

\[E[Y \mid D=1] - E[Y \mid D=0] = \tau + \underbrace{0.5 \cdot (E[X_1 \mid D=1] - E[X_1 \mid D=0])}_{\text{sesgo de selección} > 0}\]

Como los tratados tienen x1 más alto en promedio, el sesgo es positivo: OLS sobreestima el efecto del tratamiento.

OLS con control por x1 debería recuperar el efecto verdadero — pero solo si el modelo lineal es correcto y hay suficiente soporte común.

Ejercicio 1: Verificar el sesgo en una sola muestra

Antes de correr la simulación, conviene ver el problema en una muestra:

* Estadísticas descriptivas por grupo de tratamiento
tabstat y x1 x2, by(D) stat(mean sd)

* ¿Qué diferencia se observa en x1?
ttest x1, by(D)

* Estimadores punto a punto
reg y D                         // OLS sin controles (sesgado)
reg y D x1                      // OLS con control (debería ser ~2)
reg y D x1 x2                   // OLS con control irrelevante (misma conclusión)

* Visualizar el soporte común del propensity score
logit D x1
predict double pscore, pr
twoway (kdensity pscore if D==1, lcolor(blue) lwidth(medthick)) ///
       (kdensity pscore if D==0, lcolor(red)  lwidth(medthick)), ///
       legend(label(1 "Tratados") label(2 "Controles")) ///
       xtitle("Propensity Score estimado") ///
       title("Distribución del PS: ¿hay soporte común?")

¿Qué esperar? OLS sin controles dará un coeficiente mayor que 2. OLS controlando por x1 se acercará a 2. PSM también debería aproximar 2, pero sin suponer una forma funcional lineal.

Ejercicio 2: PSM con psmatch2

* Instalar psmatch2 si no está disponible
* ssc install psmatch2, replace

* Preparar orden aleatorio (necesario para NN sin reemplazo)
set seed 2025
drawnorm orden
sort orden

* PSM: vecino más cercano, soporte común, ATT
psmatch2 D x1, outcome(y) n(1) com

* Ver la estimación
* r(att) = Average Treatment Effect on the Treated

* Verificar balance
psgraph
pstest x1, both graph

* Alternativamente: solo con x1 (variable relevante)
psmatch2 D x1 x2, outcome(y) n(1) com

* ¿Cambia el resultado cuando agregamos x2?

Nota: la inclusión de x2 en el propensity score no debería cambiar el resultado porque x2 no está correlacionada con D. Sin embargo, en muestras pequeñas puede introducir algo de ruido. La regla práctica (Caliendo & Kopeinig 2008) es incluir en el PS todas las variables que afectan D o Y, no solo las que afectan D.

Simulación Monte Carlo: 500 repeticiones

Para comparar sistemáticamente OLS y PSM bajo el DGP conocido, corremos 500 réplicas:

clear all
set seed 2025

* --- Configuración de la simulación ---
local reps = 500
local n    = 1000

* Archivo para guardar los resultados
tempfile results
postfile sim ols_nc ols_ctrl psm using `results', replace

* --- Bucle de simulación ---
forval i = 1/`reps' {
    quietly {
        clear
        set obs `n'

        gen x1 = rnormal()
        gen x2 = rnormal()
        gen u  = rnormal()

        gen p = invlogit(0.5*x1)
        gen D = rbinomial(1, p)
        gen y = 2*D + 0.5*x1 + u

        * OLS sin controles
        reg y D
        local b_ols_nc = _b[D]

        * OLS con control por x1
        reg y D x1
        local b_ols_ctrl = _b[D]

        * PSM: vecino más cercano, soporte común, ATT
        drawnorm orden
        sort orden
        psmatch2 D x1, outcome(y) n(1) com noisily
        local b_psm = r(att)

        post sim (`b_ols_nc') (`b_ols_ctrl') (`b_psm')
    }
    if mod(`i', 50)==0 di "Réplica `i' de `reps' completada"
}

postclose sim

* --- Análisis de resultados ---
use `results', clear

* Estadísticas de los estimadores
summarize ols_nc ols_ctrl psm

* Distribuciones: histograma comparativo
twoway ///
    (histogram ols_nc,   width(0.08) color(red%50)    start(0)) ///
    (histogram ols_ctrl, width(0.08) color(green%50)  start(0)) ///
    (histogram psm,      width(0.08) color(blue%50)   start(0)), ///
    xline(2, lcolor(black) lwidth(medthick) lpattern(dash)) ///
    legend(label(1 "OLS sin controles") ///
           label(2 "OLS con x1")        ///
           label(3 "PSM"))              ///
    ytitle("Frecuencia") xtitle("Estimador del efecto del tratamiento") ///
    title("Monte Carlo: 500 réplicas, efecto verdadero = 2") ///
    note("Línea punteada = valor verdadero (τ = 2)")

graph export psm_vs_ols_montecarlo.png, replace width(1200)

Interpretación de resultados

La simulación debería mostrar lo siguiente:

Estimador Sesgo esperado Varianza Conclusión
OLS sin controles > 0 (positivo) Baja Sobreestima el efecto
OLS con x1 ≈ 0 Baja Insesgado si modelo es correcto
PSM vecino más cercano ≈ 0 Mayor Insesgado sin suponer linealidad

Lección 1: OLS sin controles está sesgado. El sesgo viene de la selección: los tratados tienen mayor x1 y por eso mayor y, independientemente de \(D\).

Lección 2: OLS controlando por x1 también es insesgado en este DGP — porque el modelo lineal es correcto. En la práctica no sabemos si el modelo lineal es la especificación verdadera.

Lección 3: PSM es insesgado sin suponer la forma funcional. Su costo es mayor varianza (cada muestra bootstrap selecciona controles distintos).

Extensión: ¿Qué pasa con x2?

* Repetir la simulación incluyendo x2 en el PS
* ¿Cambia el sesgo? ¿Cambia la varianza?

* En la simulación, cambiar:
*   psmatch2 D x1,    outcome(y) n(1) com
* por:
*   psmatch2 D x1 x2, outcome(y) n(1) com

* Resultado esperado:
* - Sesgo similar (x2 no genera confusión)
* - Varianza ligeramente mayor (PS más ruidoso)

Esto ilustra la regla de sobre-inclusión: incluir variables irrelevantes en el PS no introduce sesgo, pero sí puede reducir la eficiencia.

Ejercicio práctico: cambiar el DGP

Modifica el DGP y observa cómo cambian los resultados:

Variante 1: Aumentar la fuerza de la selección

gen p = invlogit(1.5*x1)     // selección más fuerte

Variante 2: Relación no lineal entre x1 e y

gen y = 2*D + 0.5*x1^2 + u  // OLS lineal será mal especificado

Variante 3: Violación del soporte común

gen p = invlogit(3*x1)       // tratados y controles casi no se superponen

En la Variante 3, el soporte común se deteriora y PSM descartará muchos tratados. La opción com en psmatch2 impone el soporte común automáticamente.

* PSM vs OLS: Simulación Monte Carlo
* Econometría Avanzada — Clase PSM en Stata
* Verdadero efecto: tau = 2

clear all
set seed 2025
set obs 1000

* --- DGP en una muestra ---
gen x1 = rnormal()
gen x2 = rnormal()
gen u  = rnormal()

gen p  = invlogit(0.5*x1)
gen D  = rbinomial(1, p)
gen y  = 2*D + 0.5*x1 + u

* --- Descriptivos ---
tabstat y x1 x2, by(D) stat(mean sd)

* --- Estimadores en una muestra ---
reg y D
reg y D x1

* Propensity score
logit D x1
predict double pscore, pr
twoway (kdensity pscore if D==1, lcolor(blue)) ///
       (kdensity pscore if D==0, lcolor(red)),  ///
       legend(label(1 "Tratados") label(2 "Controles")) ///
       xtitle("Propensity Score") ///
       title("Soporte común del PS")

* PSM en una muestra
set seed 2025
drawnorm orden
sort orden
psmatch2 D x1, outcome(y) n(1) com
psgraph
pstest x1, both graph

* --- Simulación Monte Carlo: 500 réplicas ---
tempfile results
postfile sim ols_nc ols_ctrl psm using `results', replace

forval i = 1/500 {
    quietly {
        clear
        set obs 1000
        gen x1 = rnormal()
        gen x2 = rnormal()
        gen u  = rnormal()
        gen p  = invlogit(0.5*x1)
        gen D  = rbinomial(1, p)
        gen y  = 2*D + 0.5*x1 + u

        reg y D
        local b1 = _b[D]

        reg y D x1
        local b2 = _b[D]

        drawnorm orden
        sort orden
        psmatch2 D x1, outcome(y) n(1) com noisily
        local b3 = r(att)

        post sim (`b1') (`b2') (`b3')
    }
}

postclose sim
use `results', clear

summarize ols_nc ols_ctrl psm

twoway ///
    (histogram ols_nc,   width(0.08) color(red%50)   start(0)) ///
    (histogram ols_ctrl, width(0.08) color(green%50) start(0)) ///
    (histogram psm,      width(0.08) color(blue%50)  start(0)), ///
    xline(2, lcolor(black) lwidth(medthick) lpattern(dash)) ///
    legend(label(1 "OLS sin controles")  ///
           label(2 "OLS con x1")         ///
           label(3 "PSM"))               ///
    ytitle("Frecuencia") xtitle("Estimador") ///
    title("Monte Carlo: 500 réplicas, τ = 2")
